# NH_IPO_Model

**AI를 활용한 공모주 투자전략** 연구 코드입니다. 기업·재무·시장·감성·범주형 정보를 결합한 다중입력 신경망으로 공모주의 초기 수익률을 분류하고, 입력 정보의 기여를 살펴봅니다.


## 연구 결과

2022년 IPO 보고서의 시점 외 표본은 **2019-10-22 -- 2022-01-20 상장한 167종목**입니다. 공모가 대비 상장일 시가수익률이 20% 이상인 경우를 상승군으로 분류했습니다.

| 평가 항목 | 보고된 결과 |
|---|---:|
| 분류 정확도 | 70.1% |
| 상승군 Precision | 81.0% |
| 상승군 Recall | 72.3% |
| 상승군 F1 | 76.4% |
| 전체 IPO의 평균 공모가→시가 수익률 | 51.8% |
| 상승 전망 종목의 평균 공모가→시가 수익률 | 63.3% |
| 선별에 따른 평균 차이 | +11.5%p |

위 수익률은 종목별 평균 공모가 대비 시가수익률이며, 청약 배정·현금 대기·거래비용을 반영한 포트폴리오 수익률과 다릅니다. 같은 표에서 1년 수익률은 전체 **−9.1%**, 상승 전망 종목 **−18.0%**로, 상장일 선별 효과가 장기 보유 초과성과로 이어지지는 않았습니다.

보고서 작성 이후 패치와 현재 v2 코드의 데이터·구조가 달라질 수 있으므로, 위 수치는 현재 구현으로 독립 재현한 성과가 아닙니다. 상장일 제도와 자료 가용 시점을 맞춰 다시 평가해야 합니다.

## 연구 배경과 기존 결과

2022년 보고서는 2021년 국내 IPO 시장 확대를 배경으로, 공모가 대비 시가수익률이 20% 이상일 가능성을 예측하는 방법을 제안했습니다.

기존 README에 기록된 당시 결과는 분류 정확도 약 70%, 모델이 상승을 전망한 공모주를 선별했을 때 전체 IPO 참여 대비 수익률 11.5%p 개선입니다. 이는 **당시 연구의 표본·기간·거래 가정에서 보고한 수치**이며 현재 코드로 독립 재현한 결과나 향후 성과 예측이 아닙니다. 자세한 배경은 `220315_IPO공모주모델.pdf`와 [기존 연구 설명](README.previous.md)을 참고하세요.

## 모델 구조

```text
기업·재무 특성 + 경제·감성·시장 시계열 + 범주 정보
  → 입력별 특징 추출
  → 범주별 Attention·Bias 및 특징 결합
  → Dense/잔차 블록
  → 2개 클래스의 softmax 확률
```

각 입력의 텐서 형상은 데이터 로딩 결과에서 결정합니다. 현재 `build_multimodal()`은 2개 클래스 출력을 사용합니다. 실제 학습용 레이블 생성·기간 분할은 입력 준비 함수와 함께 확인해야 합니다.

## 2022-12-08 수정 사항

- 범주형 변수 구분별 Attention 비중을 학습하는 `CategoricalAttention_v2`와 범주형 Bias 반영
- 누락된 과거 재무정보의 0 처리·마스킹
- 짧은 시계열에 대한 1D CNN 활용과 LSTM 경로 조정

이 설명은 당시 변경 동기입니다. 모든 데이터에서 학습 속도·정확도가 개선된다는 일반적 보장은 아닙니다.

## 파일 구성

## 환경과 입력

TensorFlow/Keras, NumPy, pandas, scikit-learn, matplotlib, Excel 엔진 등이 필요합니다. 현재 `requirements.txt`에는 설치 항목이 없어 별도 환경 명세를 준비해야 합니다. 가중치·Keras·커스텀 레이어의 직렬화 호환성도 확인하세요.

기본 입력 경로는 `backdata/`입니다. 코드에는 `cnnadj.csv`, `0.raw_Econ_monthly.xlsx`, `SWNEMO_Score.csv`, `mktrtn.csv`, `BB_v2.csv` 등의 입력이 있습니다. 종목 코드·날짜·결측값·범주형 인코딩을 학습 시점과 일치시켜야 합니다. 이 파일들은 복제만으로 모두 준비되는 것이 아닙니다.

## 실행 형태

입력·환경·초기 가중치·저장 경로를 준비한 뒤 저장소 루트에서 실행합니다.

```bash
python multimodal_classification_v2.py
python multimodal_test_v2.py
```

학습 스크립트는 기존 가중치를 읽는 경로도 사용하므로 완전한 무작위 초기화 학습과 구분해야 합니다. 평가 스크립트 이름의 `test`는 소프트웨어 단위 테스트를 의미하지 않습니다. 결과는 `prediction.csv` 등에 저장됩니다.

## 활용과 한계

IPO 특성별 확률 비교, 범주형 정보의 민감도 연구, 시계열·정적 정보의 결합 실험에 활용할 수 있습니다. 학습 이후의 정보가 입력에 들어가지 않도록 공모·상장 기준일을 고정하고, 시초가 매매 가능성·배정·수수료·표본 선택을 함께 검토해야 합니다. 가중치·금융자료·보고서의 재사용 권한은 각각 확인하세요.
